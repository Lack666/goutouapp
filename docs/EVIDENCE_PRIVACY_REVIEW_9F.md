# Phase9F evidence provenance and privacy boundary

All new Web/native/database tests use disposable synthetic owners, names and
messages. Native host REST creates preconditions explicitly marked `host_setup`;
the App itself performs signed prepare/confirm/execute/receipt/refresh. UUIDs,
counts, statuses and scope metadata are retained so physical deletion and other
scope preservation can be reviewed. No private account or real chat was used.

Development JWTs are issued through private fixture pipes and entered into a
password field. The native helper omits password nodes from UI evidence and
suppresses exception arguments/credential-bearing command lines. Wire evidence
records bearer presence and independently verified synthetic owner label. It
does not store Authorization values. Exact-body SHA256 compares deletion target,
confirmation and key replay without logging the body. These hashes do not cover
private chat content. No provider credential or hidden reasoning is collected.

`scripts/audit_evidence_privacy.py` now includes phase9f artifacts and the matrix.
Independent root verification runs the read-only credential pattern screen.
Final acceptance requires no findings. Pattern screening has limited coverage;
synthetic provenance and output allowlists are additional controls. This does
not certify arbitrary prose, deployed collectors or external production logs.

Historical phase evidence remains unchanged. Failed attempts keep their nonzero
exit codes. Earlier native successes precede the final recovery scope guard and
are explicitly superseded. Final native reports record the executing Mobile and
erasure source fingerprints, and cannot be replaced with Web or MockFetch results.
No screenshot/video is used as a substitute for complete signed and SQL evidence.

Final independent complete pre/post root runs both passed the credential screen
with zero findings. After evidence closure, the final independent screen covered
518 evidence files with zero findings. Final acceptance still has synthetic-only provenance and the
pattern-screening limits above; no production-log certification is claimed.
